# TechStore - Cửa hàng công nghệ hàng đầu

## 🚀 Cách chạy trang web:

### Phương pháp 1: Sử dụng Python (Khuyến nghị)
```bash
cd C:\Users\LOQ\Desktop\hhhh
python -m http.server 8000
```
Sau đó mở trình duyệt và truy cập: `http://localhost:8000`

### Phương pháp 2: Mở trực tiếp file
- Mở file `index.html` bằng trình duyệt web
- Hoặc mở file `test.html` để xem phiên bản đơn giản

## 📁 Cấu trúc file:

- **index.html** - Trang chủ chính
- **test.html** - Trang test đơn giản (không cần CSS/JS)
- **products.html** - Trang tất cả sản phẩm
- **product-detail.html** - Trang chi tiết sản phẩm
- **cart.html** - Trang giỏ hàng
- **login.html** - Trang đăng nhập
- **register.html** - Trang đăng ký
- **contact.html** - Trang liên hệ
- **profile.html** - Trang hồ sơ
- **admin.html** - Trang quản trị
- **thankyou.html** - Trang cảm ơn
- **style.css** - File CSS chính
- **script.js** - File JavaScript chính
- **products.json** - Dữ liệu sản phẩm
